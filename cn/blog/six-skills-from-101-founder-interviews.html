我把 101 期创始人访谈做成了 6 个创业技能

Solo Founder Playbook 的六个 Claude Code / Codex 技能分别做什么、数据从哪里来，以及如何试用。

问 AI 创业问题，得到的回答常常很像那么回事，但你不知道依据是什么。Solo Founder Playbook 把问题缩小：从 101 期 Starter Story 创始人访谈里提炼模式，做成六个 Claude Code / Codex skills。

这些内容从哪里来？

素材是创始人的长访谈。一套五步流程拿到字幕，按 11 个创业主题整理每期内容，再横向提炼出 80 多个重复出现的模式，并记录出现次数。这个次数只表示在这 101 期里有多少人提到，不等于某个方法对所有创业者的成功率。

六个技能，分别解决什么问题？

  • /solo-analyze：拿一个新点子，对照找问题和验证需求的真实案例。
  • /solo-failures：检查没验证就开做、现金压力、创始人倦怠等风险。
  • /solo-growth：按你的业务情况，找访谈里反复出现的获客方式。
  • /solo-patterns：按主题直接浏览模式库。
  • /solo-playbook：把一个具体目标拆成可执行的步骤。
  • /solo-roast：用尖锐的问题和访谈证据，帮你挑计划里的漏洞。

例如，别只问“怎么增长”。把客户是谁、卖多少钱、现有渠道和试过什么告诉 /solo-growth，它才能给出更贴近当前阶段的实验。访谈数据适合帮你提出假设，最后仍要拿自己的用户反馈来验证。

怎么试？

可以先在浏览器里试用，不用安装。Claude Code 的插件安装命令、Codex 安装脚本和六个技能的源码都在 GitHub 仓库，MIT 开源。

想看具体数据，可以接着读七种常见创业失败模式；想看资料怎么处理出来的，可以读五步访谈处理流程。
