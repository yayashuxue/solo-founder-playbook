101 期创始人访谈，是怎么变成创业知识库的？

Starter Story Pipeline 的五步流程：收集字幕、分析单期访谈，再提炼跨访谈的创业模式。

Solo Founder Playbook 用到了 101 期 Starter Story 创始人访谈。下面是把长视频变成可查知识库的实际流程。

第一步：列出视频

用 YouTube Data API 获取频道视频，过滤掉五分钟以下的短片。每期先有一条记录，再进入 AI 分析。

第二步：下载字幕

通过 youtube-transcript.io 获取字幕。流程可以增量运行：下次跑时，会跳过已经下载过的视频。

第三步：逐期分析

Claude 阅读每期字幕，把内容归进 11 个固定主题，包括找点子、验证、发布、营销、增长、变现和失败。分类固定，后面才能横向比较。

第四步：整理笔记

再跑一轮，把产品压缩成一句话描述，把长段访谈整理成更容易使用的要点。目的是保留原意，同时让不同访谈能互相对照。

第五步：找跨访谈模式

Claude 比较全部访谈，找反复出现的策略和工具。生成的模式文件和文字总结，成为六个 skills 使用的知识库。

这份数据能说明什么？

最后整理出 11 个类别、80 多个重复模式。出现次数只能说明这 101 期访谈里谁提到了什么；它不能证明某个做法带来了成功。这批 YouTube 访谈也不能代表所有创业公司。

流程代码和 README 已开源，里面有逐步运行和改成其他频道的方法。README 对每 100 期视频估算的费用是字幕约 5–10 美元、Claude API 约 15–30 美元；实际花费取决于视频长度、模型价格和服务套餐。

最后做出来的是 Solo Founder Playbook。想看模式库的一种具体用法，可以读失败模式整理。
